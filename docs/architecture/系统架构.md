# 系统架构

React 页面通过 FastAPI 接口访问业务服务。SQLite 保存商品、政策、工单、申请、执行凭据和审核记录。服务端统一检查身份、订单授权、对象版本和状态迁移。

```text
客服 / 主管页面
       ↓
FastAPI：身份、输入校验、订单授权
       ↓
工单查证 · 双向翻译 · 售后审批 · 人工交接
问题归集 · 改进任务 · 知识发布 · 回归评测
       ↓
SQLite：业务对象、来源快照、历史与审计
       ↘ 可选模型服务：回复草稿、翻译
```

## 责任划分

- 客服处理普通咨询、申请售后、上传材料及登记执行结果。
- 主管负责审批、未知结果对账、升级决策、任务调度、知识发布和质检。
- 角色决定可执行操作，订单授权决定可访问的数据范围。

## 一致性

更新操作携带对象版本；信息变化后旧草稿与批准状态按业务规则失效。执行记录使用幂等键，未知结果先对账。资料发布保留原文与版本，历史回复继续引用当时的来源。

## 模型调用

模型服务由后端配置，提供超时、预算、输出检查及停机控制。回复生成与翻译分别开启，生成结果经人工核对后使用。普通规则流程无需模型服务即可运行。
