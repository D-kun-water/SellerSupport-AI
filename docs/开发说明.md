# 开发说明

## 技术与目录

后端使用 FastAPI、Pydantic 和 SQLite；前端使用 React、TypeScript 和 Vite。

| 目录 | 内容 |
|---|---|
| `app/` | 接口、权限、工单、知识、售后、改进与评测 |
| `frontend/src/` | 客服与主管页面 |
| `tests/` | 后端回归测试 |
| `frontend/tests/` | 草稿恢复和知识查询逻辑测试 |
| `data/` | 业务验证空白模板及评测分组配置 |
| `scripts/` | 启动、备份、资料更新与评测 |
| `storage/` | 本地数据库与运行日志，不提交 |
| `output/` | 本地报告，不提交 |

## 独立开发服务

后端：

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

前端另开终端：

```powershell
cd frontend
npm ci
npm run dev
```

Vite 将 `/api` 请求转发到本机 `8000` 端口。FastAPI 的 `/docs` 提供接口说明，`/openapi.json` 提供接口结构。

## 检查与构建

```powershell
python -m pytest
python scripts/evaluate_rules.py
python scripts/verify_product_docs.py
python scripts/check_repository.py
npm --prefix frontend test
npm --prefix frontend run build
```

`scripts/verify.ps1` 也可执行后端测试、规则评测和前端构建。模型服务评测需单独配置凭据和预算。

## 配置与数据

复制 `.env.example` 为 `.env` 后填写本地配置。模型调用在服务端执行，前端不保存 API 密钥。回复生成和双向翻译分别控制，共用预算及停机开关。

正常启动使用空白业务库，商家资料通过页面录入。`tests/fixtures/` 只保存回归测试输入；中文测试商品由 `tests/catalog_builder.py` 构建。测试运行显式启用测试装载，普通启动不导入这些文件。改动测试来源文字后，应同步校验和与评测输入指纹，保留场景分组。

默认是单商家数据库。人员角色和订单授权分别检查；多个本地数据库不等同于多租户服务。

## GitHub 上传

在项目根目录通过 Git 提交源码；`.gitignore` 排除本地配置、数据库、日志、导出资料、依赖和构建产物。不需要制作压缩包。

```powershell
python scripts/check_repository.py
```

首次下载后按 README 安装依赖；启动器会生成缺失的前端构建和本地数据库。
